# 0013 — hosszúszőrű tacskó (variáns)

Fekvő, hosszúszőrű tacskó: a tollas szőrzet ívelt tónussávokként — a legszervesebb, leginkább
kézműves-hatású design eddig. Damaszt mező szívekkel + csont. Elsőre tisztán átment a láncon:
1/4/7/11/7/7/5 darab (7 szint), 0 nyak, leggyengébb 9,43 mm.
Ismert szépséghiba: a szegély jobb alsó íve egyenetlen (az AI rajzolta így) — reggeli döntés,
hogy zavar-e; szintetikus szegély-tisztítás lehet a következő lánc-fejlesztés.
